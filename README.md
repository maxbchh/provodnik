# Журнал ДЖД — локальная версия

Работает без Supabase и без онлайн-синхронизации. Все данные сохраняются в localStorage текущего браузера и не передаются на сервер.

## Функции
- локальная регистрация и вход; первый аккаунт становится начальником поезда;
- роли начальник поезда, учитель и проводник; назначение учителя;
- отдельный журнал оценок 1–10 и Н, редактирование и удаление;
- отдельный журнал посещаемости: был, Н, опоздал;
- график занятий/созвонов;
- домашние задания с редактированием, удалением и отметкой выполнения;
- карточка документов и формы каждого проводника: что принёс, что выдали, чего не хватает;
- примечания преподавателей;
- адаптивный интерфейс.

## Запуск локально
```powershell
npm install
npm run dev
```
Открой адрес Vite в браузере. Для сборки: `npm run build`.

## Публикация
GitHub Actions собирает сайт на GitHub Pages автоматически после изменения `main`.

## Важно о локальных данных
Данные привязаны к браузеру и устройству. На другом устройстве они не появятся. Очистка данных сайта/браузера может удалить журнал — регулярно сохраняй резервную копию через экспорт браузерных данных или используй отдельную функцию резервного копирования, когда она будет добавлена. Пароли хранятся в виде SHA-256-хэша в локальном хранилище; это не замена серверной аутентификации для конфиденциальных данных.
