# Журнал ДЖД — демонстрационная версия

Сайт на React, TypeScript и Vite. Онлайн-база данных и серверная авторизация пока не подключены.

## Возможности
- временная регистрация и вход в пределах открытой вкладки;
- роли начальника поезда, учителя и проводника;
- журнал оценок от 1 до 10 и отметка «Н»;
- таблица оценок по проводникам и занятиям: нажатие на ячейку позволяет поставить, изменить или очистить отметку;
- журнал посещаемости: был, Н, опоздал;
- создание, редактирование и удаление уроков и созвонов;
- домашние задания с описанием, сроком, привязкой к уроку и отметкой выполнения;
- карточки документов и формы проводников;
- примечания преподавателей;
- адаптивный интерфейс для телефона и компьютера.

## Важно: сохранение данных

Данные хранятся только в оперативном состоянии открытой страницы. Они не записываются в localStorage, файлы или базу данных. После перезагрузки страницы или закрытия вкладки данные и созданные аккаунты исчезают. Вход с другого устройства и совместная работа пока не поддерживаются.

Не используй демонстрационную версию для хранения настоящих персональных данных.

## Локальный запуск

```bash
npm install
npm run dev
```

Для проверки production-сборки:

```bash
npm run build
```

## Публикация

GitHub Actions автоматически собирает проект и публикует его на GitHub Pages при изменениях в ветке `main`.
